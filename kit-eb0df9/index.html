  1. Install the Email Studio plugin

    5 minNeeds Claude Code

    Download the zip and unzip it. In Claude Code, type /plugin marketplace add followed by the path to the unzipped email-studio folder, then /plugin install email-studio@email-studio. Restart the session; typing /email-studio: lists the commands.

  5. Set up your first client brand

    30 minNeeds Figma + Asana or ClickUp

    Open Claude Code in a folder for your client work and run /email-studio:new-brand with the brand's name. It asks for the Figma file, the board and the website, then writes the rules file and the layout library. Keep client folders on your machine.

  6. Run your first week

    1 hourNeeds Figma

    Run /email-studio:plan-week, then /email-studio:run-week with the brand and the Monday date. Review the deck in Figma with Present mode and approve.
