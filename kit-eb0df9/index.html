  1. Download the plugin and the kits

    2 minNothing to install

    Three zips. The plugin is for Claude Code. The app skills are the same skills, one zip each, for the Claude app. The kits hold INSTALL.md, the SOP, The Rules File, the brand extraction template, the verdict cheat sheet, the Figma scripts and the Fernhill sample brand.

  2. Install in Claude Code

    5 minNeeds Claude Code
    1. Unzip the plugin and move the email-studio folder somewhere permanent, for example ~/email-studio-plugin.
    2. In Claude Code: /plugin marketplace add ~/email-studio-plugin, then /plugin install email-studio@email-studio. Restart Claude Code.
    3. Type /email-studio: and you should see new-brand, plan-week, run-week, run-queue and sync.
    4. Connect Figma, plus Asana or ClickUp, under claude.ai Settings, Connectors.

    You need a paid Claude plan, Python 3 and Node 18 or newer (for brand extraction).

  3. Or install in the Claude app

    5 minNeeds a paid Claude plan

    Unzip email-studio-app-skills.zip. In Settings, turn on code execution and skills, then upload the skill zips you'll use (don't unzip those). Start with studio, brand-extract, rules-sweep, feedback-twice and preflight. The app has no agents or slash commands; attach the brand's BRAND.md when a skill asks.

  7. Set up your first client brand

    30 minNeeds Figma + Asana or ClickUp

    Run brand-extract on the brand's website, then /email-studio:new-brand with its name. Claude asks for the Figma file, the board and the website, then writes the Rules File and the template library. Keep client folders on your machine. A human approves every email.
